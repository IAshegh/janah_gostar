# سامانه جامع معماری سازمانی و ISO 9001:2015 | مجتمع معادن و کارخانه گچ

وب‌سایت تعاملی چارت سازمانی، اینفوگرافی زنجیره ارزش، ۱۲ روش اجرایی ریز (SOP)، کتابخانه کامل ۱۸ فرم عملیاتی قابل چاپ ISO 9001:2015، کارتابل عارضه‌یابی و نقشه راه استقرار ۹۰ روزه.

## مشاهده آنلاین (GitHub Pages)
https://iashegh.github.io/janah_gostar/

## محتوای سامانه
- **اینفوگرافی تعاملی زنجیره ارزش و چرخ PDCA ایزو 9001** (به همراه فایل‌های باکیفیت در پوشه `infographics/`)
- **چارت سازمانی هلدینگ (۲ مجموعه)** با تفکیک مالی، جایگاه امین مالک، مشاور عارضه‌یابی و بهبود و واحدهای عملیاتی
- **۱۲ روش اجرایی ریز و قابل اجرا (SOP)** منطبق با بندهای ۴ تا ۱۰ استاندارد `ISO 9001:2015`
- **۱۸ فرم عملیاتی، قابل پر کردن، محاسبه خودکار و چاپ A4** (`FRM-QMS-01` تا `FRM-MNG-02`)
- **عارضه‌یابی ۸ گلوگاه بحرانی، ماتریس RACI و نقشه راه ۹۰ روزه**
